Create a new post file from a title. It writes `<section>/<today>-<slug>.md`
with `title`, `date`, an empty `tags` list, and an empty `description` filled
in, the slug derived from the title.

```
blogin new <title> [--src <dir>] [--section <name>] [--force]
```

## Arguments

`<title>`
: the post title. The filename slug comes from it.

## Options

`-s`, `--src <dir>`
: the content directory. It defaults to `content`.
`-S`, `--section <name>`
: the section directory the post goes in. It defaults to the `home-section` from `blogin.json`, or the content directory itself when that is not set.
`-f`, `--force`
: writes over a post that already exists. Without it, an existing file stops the command.

Every option also has a one-letter spelling, listed on
[blogin build](/cli/blogin-build/#short-options).

## Example

```
blogin new "My First Post" --section posts
```

Flags are read wherever they appear, so `blogin new --section posts "My First
Post"` is the same command.
