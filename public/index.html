    Blogin

    An insanely fast static site generator written in C++. Point it at a directory of Markdown and it writes a directory of HTML you can host anywhere. No database, no runtime, nothing to install alongside it.

    Read the guide CLI Reference
    Markdown and HAML

    Write posts in Markdown with front matter. Shape pages with HAML layouts and reusable partials.
    Sections and navigation

    Sections come from the content tree, with clean URLs, a recursive menu, paginated listings, and tag pages.
    Feeds and search

    Atom feeds, a sitemap, and browser search against a prebuilt index, all generated at build time.
    CSS frameworks

    Framework profiles for Bootstrap 5, Pico, and Bulma add classes to the same semantic HTML, or use none.
    Syntax highlighting

    Fenced code blocks are highlighted server-side during the build, so pages need no client-side highlighter.
    Preview and incremental builds

    A preview server rebuilds on change and live-reloads the open page. A rebuild does only the work the change requires, and lands byte-identical to a build from scratch.
    Asset pipeline

    Stylesheets and scripts are minified, every asset can carry a hash of its content so a far-future cache never serves a stale file, and raster images get a srcset of smaller widths.
    Write in more than one language

    Each language builds into its own subtree with its own listings, taxonomies, and feeds. Translations are matched by filename, so a layout can offer a switcher that lands on the right page.
    No dependencies

    Markdown, HAML, JSON, YAML, the asset pipeline, and the preview server are all in the binary. Building it needs a compiler and CMake, and nothing else.
